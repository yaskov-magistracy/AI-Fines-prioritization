# Как контрибьютить

## Ветки и коммиты

- Ветка от `main`: `feat/краткое-описание`, `fix/...`, `chore/...`
- Коммиты — короткие, в повелительном наклонении: `добавить фильтр по VIN`
- Перед PR: `make check`

## Требования к PR

- Зелёный CI (ruff, mypy, pytest, миграции)
- Тесты на новое поведение
- Миграция, если менялись модели: `make revision m="что поменялось"`
- Никаких секретов и персональных данных в дифе, включая тестовые PDF

## Локальное окружение

```bash
make install   # зависимости + pre-commit хуки
make up        # postgres + api
make test
```

## Добавить новый экстрактор или провайдер цен

Реализуй протокол (`fines.extraction.base.Extractor` или
`fines.pricing.base.PriceProvider`), зарегистрируй в соответствующем
`factory.py` и добавь значение в `Settings`. Конвейер править не нужно.
